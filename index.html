03 / Colophon

About this website

Three files. No framework, no build step, no dependencies. The whole thing is hand-written HTML, one stylesheet and about forty lines of JavaScript. The moving gradient behind you is CSS, not WebGL.

It was built with AI assistance, and I'd rather say so than pretend otherwise, because I evaluate these systems for a living. I also run a local setup on free models, and the interesting part is where the two diverge: what the cheap tier gets right, and the specific places it falls over.

It's served from a machine in my house. That's the fun bit and also the risky bit, so the static build sits on a CDN as well. If the box is down, you're reading the cached copy and nothing breaks.
