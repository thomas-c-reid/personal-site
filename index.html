03 / Colophon

About this website

Three files. No framework, no build step, no dependencies — one HTML file, one stylesheet and about ninety lines of JavaScript. The moving gradient behind you is CSS, not WebGL.

It was built with AI assistance, and I'd rather say so than pretend otherwise — I evaluate these systems for a living. The interesting part wasn't the generation; it was the review. Every line that shipped got read, argued with, and cut where it deserved it.

It started out served from a Proxmox VM on the machine in my house, with a Cloudflare Tunnel carrying inbound requests so the router never faced the internet directly. That setup was one broadband outage away from being someone else's problem, so it now defaults to Vercel — a git push is the entire pipeline.
